privacy policy

OMA Drive · last updated 2026-11-11

OMA Drive is a personal-use integration that connects the owner's Omarchy Linux desktop to their Google Drive. It uses rclone and a fork of omarchy-gdrive. This policy describes that integration's access to Google user data.

01information accessed and purpose

With the owner's explicit authorization, the integration uses the Google Drive API to list file and folder metadata, read and download file contents, and create, upload, update, move, and delete files. These permissions let the owner use Google Drive as a folder in local applications. Google-native documents may be exported or opened using links to Google's own website.

02storage and transmission

Drive file contents and listings travel between Google's services and rclone on the owner's computer. File caches, mount configuration, and OAuth authorization tokens are stored locally, not in this public website or repository. The integration supports encrypted rclone configuration with its password held in the desktop keyring; local filesystem permissions and the security of the computer also affect protection of that data.

Cached files can remain on disk until removed by the configured cache policy or the owner. Pending uploads must be preserved until they finish. Authorization credentials are retained locally while the connection is in use.

03sharing and use limitations

The integration does not send Drive file contents, folder listings, or OAuth credentials to the software authors, GitHub Pages, or a separate application server. It does not sell Google user data, use it for advertising, or use it to train machine learning models. Files opened by the owner in other applications are subject to the owner's choices and those applications' own policies.

This public documentation site is hosted by GitHub Pages. Visiting it is subject to GitHub's privacy statement. The website contains no Drive login form or Drive data. Google's services are subject to Google's own policies.

04Google API Services

OMA Drive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

05revocation and deletion

The owner can revoke access at any time through Google Account third-party access settings. Disconnecting or uninstalling the desktop integration stops local access; removing its local authorization configuration deletes the retained tokens. Cached file contents must be removed separately if no longer wanted, after ensuring there are no pending uploads. Deleting local credentials or a cache does not itself delete files stored in Google Drive.

06contact

The maintainer of this personal integration is charleschao on GitHub. The source is available in the public fork; the original omarchy-gdrive software is by gloomyweather.
