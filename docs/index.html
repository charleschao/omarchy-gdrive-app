OMA Drive

personal Google Drive access from an Omarchy Linux desktop.

OMA Drive is a personal desktop integration built on rclone and a fork of gloomyweather's omarchy-gdrive. It lets the owner browse Google Drive folders and open, upload, edit, and remove files from local applications. The integration runs on the owner's computer; this website hosts only public documentation.

01how it works

  • the owner authorizes access to their own Google Drive through Google's OAuth sign-in
  • rclone mounts Drive as a local folder and retrieves file contents on demand
  • folder listings, temporary file caches, and authorization credentials are kept locally
  • the omarchy-gdrive package adds desktop controls and connection status

This is a personal-use integration, not a public hosted file service. It has no separate user registration, and it does not give this website access to anyone's Drive.

02data access

The requested Google Drive permission allows listing, reading, creating, updating, and deleting files, as needed to use the mounted folder. Review the privacy policy for details about data use, storage, and revoking access.

03source and contact

The personal fork is public. The original software and installation documentation are available from the upstream project. For the maintainer of this personal integration, see the charleschao GitHub profile.
